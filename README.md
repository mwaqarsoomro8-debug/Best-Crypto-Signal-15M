# Best Crypto Signal 15minute

A starter Android project with a simple BUY / SELL / WAIT dashboard and a GitHub Actions workflow to build a debug APK.

## Build APK on GitHub using a phone

1. Download and extract this ZIP on your phone.
2. Open your GitHub repository in a browser.
3. Upload the **contents** of the extracted `Best-Crypto-Signal-15minute` folder to the repository root. Keep the `.github/workflows/Android.yml` path exactly as shown.
4. Commit the files to the `main` branch.
5. Open the repository's **Actions** tab and select **Build Android APK**.
6. Tap **Run workflow** if needed, then open the completed successful run.
7. Download the artifact named `Best-Crypto-Signal-15minute-APK`. It contains `app-debug.apk`.

## Important

This is a runnable starter UI, not a live trading signal engine. BUY/SELL/WAIT buttons only change the displayed demo label. It does not fetch live market data, predict prices, or place trades. Do not use the demo label as a trading recommendation.
